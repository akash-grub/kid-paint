# Kid Paint

A retro-style paint app for iPad, made for kids and their fingers.

Tools: Draw, Eraser, Fill, Square, Rectangle, Circle, Triangle, three brush sizes, 16 colours, Undo, New and Save to Photos.

## Install on iPad

1. Open the GitHub Pages link for this repo in Safari.
2. Tap the Share button, then **Add to Home Screen**.
3. Open it from the Home Screen. It runs full-screen and works offline.

Drawings are kept on the iPad between launches. **Save to Photos** opens the share sheet; tap **Save Image**.
